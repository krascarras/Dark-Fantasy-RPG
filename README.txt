# Dark Fantasy RPG

## Current version

**v4.3**

Dark Fantasy RPG is a browser/PWA and Android WebView role-playing game.

### Current features

- Character creation and party management
- Character portraits and picture replacement
- Character removal
- Three-dot character actions menu
- Automatic game saving
- Dark fantasy story and relationship systems
- Responsive mobile interface
- Full-screen Android presentation
- PWA support

## Android build

The Android APK is generated by GitHub Actions using:

- Java 17
- Gradle 8.10.2
- Android Gradle Plugin 8.7.3
- Android WebView

The Android wrapper includes WebChromeClient support so browser features used by the game, including image/file selection and JavaScript dialogs, work correctly inside the APK.

The build workflow is:

`.github/workflows/build-apk.yml`

The APK is uploaded by the workflow as:

`Dark-Fantasy-RPG-v4.2-APK`

## Caching

The service worker uses a versioned cache (`dark-fantasy-rpg-v4.3`) so a new game build can invalidate older cached versions.

If the web/PWA appears to show an older version after an update, close the installed PWA/browser tab and reopen it.

## AI

The game is being prepared for a local AI architecture rather than requiring Gemini credentials in the client. The game should continue to provide its built-in story behaviour when a local AI endpoint is unavailable.

## Repository

This repository contains the source files and GitHub Actions workflow used to build the Android version of Dark Fantasy RPG.
